# Panduan Penggantian Aset Video & Gambar

Direktori ini digunakan untuk menyimpan video dan foto dokumentasi pengerjaan nyata **Tukang Bangunan Banjarmasin Banjarbaru**.

## 1. Video Hero (`assets/videos/hero-construction.mp4`)
- **Nama File**: `hero-construction.mp4`
- **Lokasi**: `assets/videos/hero-construction.mp4`
- **Spesifikasi Rekomendasi**:
  - Resolusi: 1080p (1920x1080) atau 720p (1280x720)
  - Rasio: 16:9 landscape
  - Durasi: 10 - 30 detik (looping)
  - Format: MP4 (H.264 / AAC)
  - Karakteristik: Video pengerjaan asli pemilik usaha/tukang di proyek (misal: pengawasan pondasi, pemasangan keramik, atau inspeksi plesteran).
  - Catatan: Video disetel otomatis *muted* dan *loop*. Gambar poster (`assets/images/hero-poster.jpg`) otomatis tampil sebagai fallback saat video sedang dimuat atau jika peramban pengguna memblokir autoplay.

## 2. Gambar Poster & Dokumentasi (`assets/images/`)
- `hero-poster.jpg` (Rasio 16:9, ~1920x1080): Poster pratinjau video hero / latar belakang saat video belum terputar.
- `about-owner.jpg` (Rasio 4:3, ~1200x900): Foto dokumenter mandor / kepala tukang di lapangan dengan catatan proyek.
- `project-01.jpg` (Rasio 4:3 atau 16:10): Dokumentasi pengerjaan lantai keramik / granit presisi.
- `project-02.jpg` (Rasio 4:3 atau 16:10): Dokumentasi renovasi rumah tinggal di Banjarmasin / Banjarbaru.
- `project-03.jpg` (Rasio 4:3 atau 16:10): Dokumentasi pekerjaan plafon gypsum / finishing interior.

Untuk mengganti aset, cukup salin file baru Anda ke folder ini dengan nama file yang sama persis.
